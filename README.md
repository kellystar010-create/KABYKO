# KABYKO
KABYKO — Coalition pour l’Environnement et le Bien Commun est une organisation engagée dans la défense de l’environnement, la justice sociale et le développement durable. À travers l’action citoyenne, la sensibilisation et le plaidoyer, KABYKO œuvre pour construire une société plus responsable, solidaire et respectueuse des ressources naturelles...
